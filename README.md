# bibig

bibig is a React workout tracker with account storage through its REST backend and optional local IndexedDB storage. See [frontend connection instructions](FRONTEND_API.md) and [backend setup](backend/README.md).

The Android Capacitor wrapper and emulator/phone API setup are documented in [ANDROID.md](ANDROID.md).

For the no-cost Cloudflare Pages + Render + Supabase deployment path, see
[DEPLOYMENT.md](DEPLOYMENT.md).
